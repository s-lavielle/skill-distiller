## Note sur la numérotation

Ce cas a été produit **avant l'ajout de l'étape de réconciliation** (le
processus s'amende lui-même — voir `SKILL.md`, « Rappels »). La
numérotation actuelle du workflow décale donc les derniers artefacts :

- `02-amendements.md` = aujourd'hui `04-amendements.md` ;
- `03-skill-final.md` = aujourd'hui `05-skill-final.md`.

L'étape 3 (réconciliation) est sautée ici : une seule source était en
jeu, la synthèse brute fait foi.
